Speedhack mod for BATTD.


F2 key: 2x speed

F3 key: 5x speed

F4 key: 10x speed

F1 key: Normal fast forward speed

F8 key: debug key used for testing (prints values to console)

Stacks with the Fast Forward toggle (for example if FF is on F3 would be 15x speed)

Put .dll in Mods folder. Melonloader 0.7.1 needed. Barely tested so use at your own risk.
